# 🌍 Central de Becas - Oportunidades Internacionales

## 📘 Descripción
La **Central de Becas** es una plataforma web que reúne oportunidades académicas y profesionales en **todos los niveles** (pregrado, maestría, doctorado, posdoctorado, internships, cursos cortos, escuelas de verano, fellowships, competencias, etc.) y en **todas las áreas** (STEM, ciencias sociales, artes, humanidades, salud, derecho, economía).  
Su objetivo es **democratizar el acceso a la información**, evitando que se pierdan becas por desconocimiento.

---

## 🏗️ Estructura del proyecto
- `index.html` → Página principal con buscador, filtros y secciones.  
- `style.css` → Estilos visuales (colores, tipografía, diseño responsivo).  
- `script.js` → Lógica de la aplicación (carga de datos, filtros, buscador).  
- `becas.json` → Base inicial de datos de becas (se conecta luego con Google Sheets).  
- `assets/` → Carpeta con imágenes y logos de fuentes confiables.  
- `README.md` → Este documento con instrucciones y guía del proyecto.
